# Linus Lind Portfolio

Static portfolio site prepared for GitHub Pages.

## Structure

- `index.html` - site entry point served by GitHub Pages
- `public/css/` - extracted stylesheet files
- `public/js/` - Tailwind config and site behavior scripts
- `public/assets/documents/` - downloadable files such as the resume
- `public/assets/images/` - screenshots, profile photos, thumbnails
- `public/assets/icons/` - favicons and social/brand assets

## Local updates

- Replace placeholder links in `index.html` with your GitHub, LinkedIn, and other profiles.
- Add new screenshots and other files under `public/assets/` and reference them from `index.html`.
- Keep asset paths relative, for example: `public/assets/images/project-shot.jpg`.

## GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, enable GitHub Pages from the main branch root.
3. Your `index.html` will be served automatically.
4. The `.nojekyll` file keeps GitHub Pages from applying Jekyll processing to the site.
